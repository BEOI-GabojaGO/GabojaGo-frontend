# 가보자GO

> 대화 한 번으로 복잡한 여행 조건을 정리하고, 가능한 날짜의 항공권을 한 번에 탐색하는 AI 항공권 검색 서비스

## 서비스 소개

가보자GO는 사용자의 여행 조건을 대화로 이해하고 조건에 맞는 왕복 항공권을 찾아주는 항공권 중개 플랫폼입니다. 아시아 지역을 시작으로, 사용자가 일일이 날짜와 가격을 바꿔가며 검색해야 하는 불편을 줄이는 것을 목표로 합니다.

## 채팅 화면 데모

`npm run dev`로 실행한 뒤 `/chat`에서 채팅 화면을 확인할 수 있습니다. `/flights`의 **대화로 여행 조건 정하기** 카드에서도 이동할 수 있습니다.

현재 채팅은 화면 구성과 사용자 흐름 확인용입니다. 예시 문구에서 출발지·목적지·월·박 수·예산·주말 희망 여부를 브라우저 안에서 간단히 표시하며, AI 서버 또는 백엔드 API를 호출하지 않습니다. 대화와 조건은 새로고침하면 사라지고 **조건 확인하기** 버튼도 실제 항공권 검색을 시작하지 않습니다.

백엔드 채팅 API가 완성되면 `src/lib/chat-demo.ts`의 임시 규칙을 API 호출로 교체합니다. Groq API 키를 프론트엔드에 넣거나 브라우저에서 FastAPI 내부 주소를 직접 호출하지 않습니다.
